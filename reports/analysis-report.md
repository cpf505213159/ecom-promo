# 大促 GMV 归因与备货 · 分析报告

> 配套：`notebooks/01_gmv_decomposition.ipynb`（可运行）｜`sql/01_gmv_attribution.sql`（生产逻辑）
> **数据是同构的**：四个效应按已知参数埋入，用于验证分解是否拆对。

---

## 摘要

2025 双 11 GMV 同比 **+60.4%**。复盘会上有两种解释：「投放加码带来流量」和「凑单机制拉高客单价」。
两者都对了一半，但都漏了最关键的第三块：**品类结构变了**。

| 结论 | 数值 |
|---|---|
| GMV 同比 | +60.4%（2.99 亿 → 4.80 亿元） |
| 客流 / 转化 / 客单贡献 | 28.7% / 25.8% / **45.5%** |
| 分解闭合误差 | **0.00 元** |
| 客单价增长中的结构贡献 | **35.8%**（15.3 / 42.8 元） |
| 增量集中度 | 数码 + 美妆 = 59.9% |
| 缺货率 12% → 5% 的代价 | 库存 +9.4% |

## 一、数据与口径

### 1.1 数据形状

| 项 | 设定 |
|---|---|
| 粒度 | 品类 × 日 × 大促期 |
| 品类 | 8 个（女装、男装、美妆、食品、母婴、数码、家居、运动） |
| 期数 | 2024 与 2025 双 11，各 11 天 |
| 字段 | `uv`、`cvr`、`aov`、`orders`、`gmv` |
| 行数 | 176 |

### 1.2 口径一致性是前提

分解要想闭合，三个指标必须同源：

1. `orders ≈ uv × cvr`
2. `gmv ≈ orders × aov`
3. 退款、去重、时间归属三件事在两期用同一套规则

**真实项目里报告「误差 3% 以内」，误差全部来自口径**，不是公式。本项目在同构数据上闭合误差为 0，
恰好说明「公式没错」，而不是「我们做得比别人准」。

### 1.3 五个口径陷阱

| 陷阱 | 后果 |
|---|---|
| 用 PV 代替 UV | 客流效应虚高 |
| 定金与尾款分属两期 | 客单效应虚高 |
| 退款不剔除 | GMV 虚高，且两期退款率不同会扭曲同比 |
| 品类改版未回滚 | 结构效应失真 |
| 跨端 UV 未合并 | 客流效应高估 |

## 二、三层分解

```
GMV = UV × CVR × AOV
ΔGMV = ΔUV·CVR₀·AOV₀ + UV₁·ΔCVR·AOV₀ + UV₁·CVR₁·ΔAOV
```

| 项 | 金额（万元） | 占增量 |
|---|---:|---:|
| 2024 GMV | 29,926 | — |
| 2025 GMV | 48,011 | — |
| **同比增量** | **18,085** | +60.4% |
| 　客流效应 | 5,196 | 28.7% |
| 　转化效应 | 4,657 | 25.8% |
| 　客单效应 | 8,232 | **45.5%** |
| 合计校验 | 18,085 | 100.0% |

闭合误差 `0.00` 元。

**结论一**：客单贡献最大，接近一半。只讲「流量涨了」的复盘，漏掉了最大的那块。

但「客单贡献」还不能归功于运营——要看它是「同品类卖得更贵」还是「贵的品类卖得更多」。
这就是下一层要解决的问题。

## 三、结构 vs 自身

| 指标 | 总体变化 | 结构效应 mix | 自身效应 within | 结构占比 |
|---|---:|---:|---:|---:|
| 转化率 CVR | +0.46 pp | **-0.04 pp** | +0.50 pp | -8.7% |
| 客单价 AOV | +42.8 元 | **+15.3 元** | +27.5 元 | **35.8%** |

两件事值得说：

1. **转化率提升基本来自自身**（mix 甚至是负的）。说明大促的转化优化是真动作，不是结构假象。
2. **客单价增长里有三成半是结构**。数码与美妆的流量份额分别涨了 2.7 / 1.9 个百分点，
   把平均客单价「抬」上去了。

**为什么这条最容易被误判**：如果只看三层分解，会得出「客单效应 45.5%，说明凑单机制有效」。
下一轮继续加大凑单力度，但同品类的客单价其实只贡献了 27.5 元——预期会落空。

> 顺带一个反直觉的性质：**纯流量结构变化也会造出「假的」转化效应与客单效应**。
> 单元测试 `test_pure_traffic_creates_fake_effects` 专门把这件事固定住了。

## 四、增量从哪来

| 品类 | 2024 GMV（万元） | 2025 GMV（万元） | 贡献占比 | UV 份额变化 |
|---|---:|---:|---:|---:|
| 数码 | 5,048 | 11,129 | 33.6% | +2.70 pp |
| 美妆 | 5,522 | 10,272 | 26.3% | +1.88 pp |
| 女装 | 5,406 | 7,432 | 11.2% | -1.54 pp |
| 食品 | 3,952 | 5,726 | 9.8% | +0.22 pp |
| 家居 | 2,098 | 3,100 | 5.5% | -0.23 pp |
| 男装 | 3,408 | 4,241 | 4.6% | -2.23 pp |
| 母婴 | 3,236 | 4,060 | 4.6% | -1.12 pp |
| 运动 | 1,256 | 2,052 | 4.4% | +0.31 pp |

数码 + 美妆贡献 **59.9%** 的增量，且份额双双上升——这两个是本次大促的引擎。
但它们的备货特性完全不同：数码客单价高、SKU 少、断货代价大；美妆 SKU 多、周转快、效期敏感。
**备货不能用同一套参数**。

## 五、备货与缺货率

```
Q = μ·(1 + k·CV)，缺货率 = 1 - Φ(k)
```

| 目标缺货率 | 安全系数 k | 备货量指数 | 库存金额（万元） |
|---|---:|---:|---:|
| 20% | 0.842 | 1.22 | 3,188 |
| 12% | 1.175 | 1.31 | 3,416 |
| 5% | 1.645 | 1.43 | 3,737 |

从 12% 做到 5%，库存金额从 3,416 万涨到 3,737 万（**+9.4%**），换 7 个百分点缺货率改善。

这个取舍必须业务定：缺货损失 GMV 与体验，压货损失现金与折损。
分析师的活是把曲线算准，不是替业务选点。

> 简历里的「缺货率 12% → 5%」就是这条曲线上的两个点；配套的备货建议是「数码按 95% 服务水平、
> 美妆按 88%、长尾品类按 80%」——因为三者的断货代价不同。

## 六、结论与建议

**给运营**：

1. 复盘口径固定为三层分解 + mix/within，不要再出现「因为流量涨了」这种单因归因。
2. 客单价目标要剔掉结构影响后再考核，否则「多上高客单品类」就能刷指标。
3. 数码与美妆要独立准备货方案，不能按全站平均系数。

**给数据**：

1. 分解脚本应该固化进看板，每期自动跑，闭合误差作为数据质量指标（非 0 就报警）。
2. 品类口径变更要有映射表，否则历史对比全部失真。

## 七、局限

| 局限 | 影响 | 下一步 |
|---|---|---|
| 拆的是恒等式，不是因果 | 回答不了「不做大促会怎样」 | 需要地理对照或合成控制 |
| 数据是同构的 | 闭合误差恰好为 0 | 真实数据误差 2%~5%，来自口径 |
| 备货用正态近似 | 厚尾与断档会低估 | 改历史分位数或模拟法 |
| 未算缺货的实际损失 | 缺货率→GMV 损失差一个替代购买率 | 需要「缺货期间替代购买」的行为数据 |
