# 数据字典与口径说明

> 描述的是**生产表的结构与口径**（可带走的部分）；`outputs/promo_category_daily.csv` 是同构数据。

---

## 一、输入表：品类日汇总

一行 = 一个品类 × 一天 × 一期大促。

| 字段 | 类型 | 口径 | 备注 |
|---|---|---|---|
| `year` | int | 大促年份（2024 / 2025） | 两期对比的键 |
| `promo` | str | 大促名称 | 本项目只做双 11 |
| `date` | date | 日期 | 11-01 ~ 11-11 |
| `day_index` | int | 期内第几天（0-based） | 用于看节奏 |
| `category` | str | 一级品类 | 8 个 |
| `uv` | int | 当日去重 UV（跨端已合并） | **不要用 PV 代替** |
| `cvr` | float | 下单转化率 = 订单 / UV | 已剔除退款单 |
| `aov` | float | 客单价 = GMV / 订单 | 已剔除运费与退款 |
| `orders` | int | 支付订单数 | 与 cvr、aov 同源 |
| `gmv` | float | 支付金额 | 与 orders、aov 自洽 |

**三条一致性约束**（任一不满足，分解就会出现残差）：

1. `orders ≈ uv × cvr`
2. `gmv ≈ orders × aov`
3. 三个指标必须来自同一批订单（同源过滤退款、同源去重）

## 二、口径陷阱

| 陷阱 | 后果 | 处理 |
|---|---|---|
| 用 PV 代替 UV | 客流效应虚高，转化效应被压低 | 统一用去重 UV |
| 定金与尾款分属两期 | 客单效应被夸大 | 按支付完成时间归属 |
| 退款不剔除 | GMV 虚高，且两期退款率不同会扭曲同比 | 统一剔除，且在报告里注明 |
| 品类改版（拆分/合并） | 结构效应失真 | 用映射表回滚到同一口径 |
| 跨端 UV 未合并 | 客流效应被高估（同一人被算两次） | 按设备 + 账号合并 |

## 三、输出指标口径

| 指标 | 定义 |
|---|---|
| 客流效应 | `ΔUV × CVR₀ × AOV₀ × 天数` |
| 转化效应 | `UV₁ × ΔCVR × AOV₀ × 天数` |
| 客单效应 | `UV₁ × CVR₁ × ΔAOV × 天数` |
| 闭合误差 | `ΔGMV -（三项之和）`，恒等式下应为 0 |
| mix（结构效应） | `Σ (w₁ - w₀) × 指标₀`，CVR 按 UV 份额、AOV 按订单份额 |
| within（自身效应） | `Σ w₁ × (指标₁ - 指标₀)` |
| 缺货率 | `1 - Φ(k)`，k 为安全系数 |
| 备货量指数 | `Q / μ = 1 + k·CV` |
